# sleeper-cell

How many poisoned documents does it take to plant a backdoor in a language model?

Goal: reproduce, at small scale and across 3 model sizes, the finding that a fixed number of poisoned samples (around 250) backdoors models regardless of size. Stretch: detect the backdoor with a linear probe.

Reference: Anthropic, UK AISI and the Alan Turing Institute, "A small number of samples can poison LLMs of any size" (2025).
